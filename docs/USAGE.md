# Veyra Assist 简明使用说明

适用版本：**1.5.2-beta.3 / Windows x64 预发布**。

索引：[功能](#功能) · [支持环境](#支持环境) · [开始使用](#开始使用) · [Debug 反馈](#debug-反馈) · [高级资料](#高级资料)

## 功能

- **首页快捷设置**：对局悬浮窗、自动接受、自动匹配，与完整设置页同步保存。自动接受缺省开启，旧配置明确关闭时保持关闭；自动匹配缺省关闭。
- **选人辅助**：支持布局中的自动定位；查看候选英雄胜率与登场率、队友近期战绩和当前英雄统计。
- **局内辅助**：自动识别海克斯标题，展示相关统计；装备面板提供热门装备、鞋子、核心组合和出门装，可收起与恢复。
- **对局与战绩**：双方对局面板、召唤师查询、队列和战绩筛选，以及符文、构建、时间线等详情。
- **自动化与工具**：选禁英雄、英雄配置、功能搜索；右下角更新日志可离线查看版本说明。
- **外观**：浅色冷灰、深色石墨、低饱和蓝灰、雾紫灰四套快捷配色；支持导入本地图片作为主窗口壁纸和调整蒙层深度。

完整入口见 [功能索引](FEATURES.md)。旧 Mini 白框弹窗已停用；首页的对局悬浮窗是另一个保留功能。

### 外观与图片导入

主窗口右上方“外观”可切换配色，也可打开“自定义外观”选择四套主题。导入图片时进入 **自定义外观 → 背景图片设置 → 自定义壁纸 → 浏览**，选择本地文件，再通过“蒙层深度”调整背景与文字的对比。

图片应用于**主窗口背景**，按居中裁剪显示；这项功能不会替换所有浮层或任意界面皮肤。程序在本地保存背景模式、原文件路径和蒙层设置，继续从原路径读取图片；它不是把图片复制进程序包。移动或删除原文件后需要重新选择。通过本版启动脚本运行时，这些设置位于该便携目录的 `user-data` 中。

四套主题和合成图片演示见 [预览说明](PREVIEWS.md)。

## 支持环境

当前提供 Windows x64 程序 ZIP。选人自动定位需支持的客户端布局、客户端前台且窗口稳定；局内自动窗口映射覆盖 1920×1080、2560×1440，并要求游戏窗口完整落在单个显示器内。

4K 与不同缩放比例适配正在评估。macOS 的 Veyra 功能尚未验收；Linux 暂无支持承诺。识别与统计受画面、游戏版本、数据源和网络影响，异常时可能暂停或不显示。

## 开始使用

1. 到 [beta.3 Release](https://github.com/Aevrilen/veyra-assist/releases/tag/v1.5.2-beta.3) 下载程序 ZIP 和说明；选择名称带 `VeyraAssist`、版本号和 `Windows-x64` 的文件。
2. 退出旧实例，把 ZIP **完整解压至新的、较短目录**，运行 `启动Veyra.cmd`。不要在压缩包内运行或覆盖正在使用的文件。Source code 是源码，不是程序。
3. 登录游戏客户端，确认应用已连接，在首页按需设置快捷开关。
4. 进入选人时保持客户端前台和窗口稳定，等待自动定位；进入支持的局内场景后，使用海克斯识别和装备面板。

新包 `user-data` 初始为空。迁移旧配置前，先退出程序并备份，按该版随包说明操作；回退时退出当前版，再从保留的旧目录启动。

## Debug 反馈

1. 先记录应用版本、出现问题的场景、复现步骤、分辨率与系统缩放，以及预期和实际行为。
2. 应用能启动时，打开 **设置 → 帮助与修复**，可打开日志目录，或选择 **导出反馈 ZIP** 并指定保存位置。
3. 检查 ZIP 内容，再私下发给维护者。导出不会自动上传；公开 Issue 只放必要的脱敏摘要，不附原始日志、完整 `user-data` 或私人截图。

如果应用无法启动，先提供启动脚本窗口中的错误文字（如有）、应用版本和复现步骤。通过本版 `启动Veyra.cmd` 启动时，日志位于解压目录下的 `user-data/logs/`；若该目录已有日志，可先检查并脱敏，再私下提供相关文件，不要发送整套配置。应用能启动后再使用反馈 ZIP 导出。日志导出的范围与数据位置见 [隐私与反馈](PRIVACY.md)。
