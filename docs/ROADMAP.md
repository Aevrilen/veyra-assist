## 执行优先级

1. 先做好识别稳定性、不同硬件的高低性能档，以及 4K / DPI 等必要适配（方向 1）。
2. 完善识别自动化的剩余环节，增加统一显示／隐藏快捷操作（方向 7、8）。
3. 按审查推进 UI 美术优化与自定义装备构筑导入（方向 5、4）；UI 审查准备可提前。
4. 在统计与数据基础稳定后，开发英雄胜率对比和海克斯／装备特殊组合推荐（方向 2、3）。
5. 最后建立有充分数据支持的评分系统（方向 6）。

## 发版同步清单

每次公开发版时一起核对以下内容，不单凭候选分支或离线测试把功能改为上线：

- [ ] 首页版本和下载入口指向实际发布包及对应源码。
- [ ] 功能索引和 Todo 区分已发布、待整合与计划。

- [ ] 更新与该版一致的实际组件界面预览，只使用可公开的模拟或脱敏数据。
- [ ] 包内新说明与仓库同步。历史 ZIP、标签和旧版本说明保持原样。
