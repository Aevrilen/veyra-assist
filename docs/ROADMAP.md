## 近期优先级

1. 推进新版自动定位，覆盖窗口几何、DPI、多屏和画面变化；通过实机验收后再讨论启用策略。
2. 合入并复测已知 bug，重点检查跨局、缓存、识别超时和状态残留。
3. 清理原版冗余通知和联系入口，核对公告、统计、更新等继承网络行为。
4. 验收已同步的日志反馈 hotfix：真实保存 / 取消 / 打开目录、应用启动 / 退出及脱敏结果；完成程序包独立许可核验后公开预发布。后续完善用户预览流程。
5. 补齐干净源码构建依赖、许可证和合成回归数据，再准备公开测试包。

## 暂缓与长期事项

- 一键拉起游戏的配置问题暂缓，根因尚未确认，不写成已解决。
- 扩充分辨率、窗口模式和硬件覆盖，收集可复现的匿名统计结果。
