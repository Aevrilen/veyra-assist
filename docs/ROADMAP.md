# 路线图 / Todo

以 [已发布的 1.5.2-beta.3](https://github.com/Aevrilen/veyra-assist/releases/tag/v1.5.2-beta.3) 为功能口径。功能与入口见 [功能索引](FEATURES.md)，使用见 [简明说明](USAGE.md)。

## 已发布

- [x] 选人辅助：候选英雄统计、队友近期表现，以及支持布局中的自动定位。
- [x] 首页对局悬浮窗、自动接受、自动匹配快捷开关，与设置页同步持久化。
- [x] 内置离线更新日志与未读标记。
- [x] 停用旧 Mini 白框窗口、倒计时与临时按钮，保留原对局悬浮窗。
- [x] 局内海克斯 OCR、统计展示、装备推荐及分类切换（沿用原实现）。
- [x] 召唤师与历史战绩查询、对局面板、战绩详情及筛选。
- [x] 日志目录与反馈 ZIP 导出（用户主动保存、检查后提交）。
- [x] 仓库 beta.3 功能展示、模拟界面图和简明使用说明源稿。

“已发布”表示程序包包含实现。beta.3 新增能力的验证范围和一次选人自动定位观察见 [版本说明](https://github.com/Aevrilen/veyra-assist/blob/v1.5.2-beta.3/docs/releases/1.5.2-beta.3.md)；局内 OCR 在本版没有新的修复。

## 发版同步清单

每次公开发版时一起核对以下内容，不单凭候选分支或离线测试把功能改为上线：

- [ ] 首页版本和下载入口指向实际发布包及对应源码。
- [ ] 功能索引和 Todo 区分已发布、待整合与计划。
- [ ] 使用说明保留原索引，正文覆盖功能、环境、开始使用和 Debug 反馈。
- [ ] 更新与该版一致的实际组件界面预览，只使用可公开的模拟或脱敏数据。
- [ ] 包内新说明与仓库同步。历史 ZIP、标签和旧版本说明保持原样。
