# 路线图与验证状态

本发布分支对应 1.5.2-beta.3。旧发布记录仍保留；本页按当前源码和已有证据更新，尚未完成的覆盖项不视为实机验收通过。

## 当前状态

| 项目 | 验证边界 |
| --- | --- |
| 选人辅助、海克斯识别、装备推荐 | 原有有限本机测试；本版没有新的局内 OCR 修复或认证 |
| 选人自动定位 | beta.3 支持布局中自动触发；算法前置候选完成一次真实 1280×720 选人观察，其他 DPI／布局待扩展 |
| 首页快捷开关 | 与原设置同步；包含对局悬浮窗、自动接受、自动匹配；定向测试和浏览器夹具已检查 |
| 内置更新日志 | 离线内容、入口和已读版本持久化已集成，浅深主题四种宽度共 8 组夹具检查 |
| Mini 白框修复 | 继续停用旧窗口和入口，不恢复其倒计时或临时操作按钮 |
| 日志反馈 ZIP | 现有实现保留；用户应使用私密反馈渠道，不上传原始 user-data |
| beta.3 程序包 | 331 项定向测试、类型／构建与归档完整性通过；未做新包 GUI 或真实游戏复测 |

具体来源、实测时间口径及清洁源码差异见[版本说明](releases/1.5.2-beta.3.md)。

## 后续工作

1. 扩展自动定位的 DPI、布局、多客户端、跨局与退出重连覆盖，继续验证几何缓存和安全重试，不把单次观察外推到全部环境。
2. 排查已知识别／缓存／状态重置问题，局内海克斯、装备 OCR 分别验证；避免将选人自动定位结果当作局内 OCR 验收。
3. 验证真实用户配置迁移、反馈对话框、取消和脱敏边界，按必要范围完善隐私反馈流程。
4. 按后续整合范围处理遗留通知入口、界面与交互问题；以明确交付和验证记录更新状态，避免频繁发布未整合改动。
5. 完善可复现构建、依赖准备、安装说明及经授权脱敏的实机截图。

一键启动游戏配置问题仍待确认根因；平台／硬件覆盖及 macOS 支持不由上游状态直接推定。
