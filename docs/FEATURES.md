## 版本与验证

发布程序为 `VeyraAssist-1.5.2-beta.3-0e54d71f-Windows-x64.zip`，公开源码映射 `944f67f62e13f437a322de133d01c021d3dc983c`。原始构建提交、文件校验及测试范围见 [官方 Release](https://github.com/Aevrilen/veyra-assist/releases/tag/v1.5.2-beta.3) 与 [对应版本说明](https://github.com/Aevrilen/veyra-assist/blob/v1.5.2-beta.3/docs/releases/1.5.2-beta.3.md)。

beta.3 的新增项是选人自动定位、首页快捷开关和内置更新日志。海克斯 OCR 与装备推荐延续旧实现，OCR 预处理、跨版本缓存目录迁移与启动修复仍待整合；不因界面展示将其标为已发布。

自动定位前置候选有一次 1280×720 真实选人成功观察；本次发布说明没有宣称新包已完成所有环境实测。局内自动窗口映射的代码条件为 1920×1080 或 2560×1440，且窗口完整处于单个显示器，见 [game-frame-layout.ts](https://github.com/Aevrilen/veyra-assist/blob/v1.5.2-beta.3/src/main/shards/mayhem-assistant/game-frame-layout.ts)。4K 与更多 DPI / 多屏环境仍在评估。
