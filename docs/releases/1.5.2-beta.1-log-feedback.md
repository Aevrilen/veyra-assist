# 1.5.2-beta.1 日志反馈测试版

程序包发布入口为 [GitHub Releases](https://github.com/Aevrilen/veyra-assist/releases)。此版本保持预发布状态；公开分发核验尚未完成时不会提供程序附件。普通用户下载 Assets 内的程序 ZIP，GitHub 自动生成的 Source code 是源码归档。

## 更新范围

- 日志按本地日期保存，同日重启追加，保留运行开始 / 结束标记与大小分卷。
- 日志目录按钮指向实际写入目录；退出时等待末尾日志送达文件 transport 后结束。
- “帮助与修复 → 导出反馈 ZIP → 选择保存位置”，整理近期脱敏诊断日志和版本 / 系统 / 显示环境信息，完成后尝试打开所在目录；不自动上传。
- 最多读取 20 个文件、总计 32 MiB、每文件 8 MiB。超限保留近期完整记录，空日志目录仍可导出环境信息。原始日志不修改，配置、数据库、截图、聊天和 Cookie 不加入 ZIP。

使用前退出旧版，将程序解压到新目录后使用包内启动脚本；不要覆盖运行中的文件。退出测试版后，可重新从旧目录启动以回退。反馈 ZIP 请先检查内容，再私下发送给维护者。

## 已有验证和限制

原交付记录包含 17 项离线测试通过、Node 类型检查、一次串行生产构建、模拟按钮状态验证，以及 40/40 条背压日志加 run-end 记录。公开移植后再次单进程运行四个日志专项测试文件，17 项全部通过；逐项核对指定增量与既有清理项，不重复全量构建。这些结果不等于真实游戏环境验收。

真实保存对话框、Explorer 打开和完整应用启动尚未实测；窗口拖动错位、局内海克斯和装备显示问题未纳入修复。新版自动定位、跨局缓存及其他开发中补丁没有合入本次移植；不能从该版本推断它们已可用。
