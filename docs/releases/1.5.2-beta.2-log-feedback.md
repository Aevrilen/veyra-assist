# 1.5.2-beta.2 日志优化公开修订版

Windows x64 预发布。程序通过 [Releases](https://github.com/Aevrilen/veyra-assist/releases) 提供；普通用户下载 `VeyraAssist-1.5.2-beta.2-log-feedback-public.zip`，并阅读使用说明。Source code 是源码归档，不能直接启动。

## 与上一交付包的区别

- 保留 beta.1 的日志按日期追加、退出排空、实际日志目录和本地脱敏反馈 ZIP 功能；没有合入其他开发工作树的自动定位、UI 或跨局缓存候选。
- 使用公开源码的清理状态重新编译主进程、preload 和全部 renderer。百科摘录、两项来源待明的非核心个人资料操作及静态端点补全表继续保持移除；选人、OCR、装备和手动校准核心流程不因此改动。
- 保留提权入口，从 Johannes Passing 的固定官方 LGPL-2.1-or-later C 源码重建独立 helper。完整对应源码、构建命令和许可证随包提供；旧的 opaque helper 不分发。
- 原已禁用的 Akari 更新生命周期保持禁用；不携带未调用的 updater 可执行文件。两平台 magic 模块保留固定 Akari MIT 来源、摘要及原作者归属。
- Electron、native addon、JavaScript 依赖、Python/RapidOCR/模型沿用已审核运行时。依赖解析未升级；原始 beta.1 ZIP 和说明不修改、不覆盖。新包元数据记录真正编译的公开源码提交。

## 使用和反馈

在非游戏期间退出旧版本，将 ZIP 完整解压到新的目录后运行“启动 Veyra Assist.cmd”；不要覆盖运行中的文件。程序沿用原有 profile，不删除旧目录和设置。回退时退出测试版，再从旧目录启动。

日志反馈入口：“帮助与修复 → 导出反馈 ZIP → 选择保存位置”。最多读取20个近期日志、总计32 MiB、每文件8 MiB，超限保留近期完整记录。空日志目录仍可导出环境信息；不自动上传，原始日志不修改。先检查内容，再私下发给维护者，勿公开原始日志或反馈 ZIP。

## 验证边界

日志专项四文件、17项测试已通过。helper 的无提权帮助参数已运行。修订包的串行构建、隔离 profile 启动和合成输入检查结果以该 Release 发布说明为准；不把包装检查等同真实游戏验收。

真实保存对话框、Explorer 打开、完整主界面和游戏内流程仍待用户验收；新自动定位默认关闭且未纳入此修订。此前窗口拖动错位、局内海克斯和装备显示问题尚未确认修复。本包未签名，Windows 可能提示未知发布者；发布状态保持 prerelease。

## 构建与许可

`scripts/windows-portable/rebuild-public.cjs` 从干净公开提交构建应用，并使用显式输入的已审核旧运行时。它重建整个 `out/`、仅从公开跟踪文件及校验过的外部依赖重建一方资源，不继承旧应用资源；只有独立 OCR runtime 和依赖继续复用。新输出目录必须不存在，删除操作限定于本轮新建目录。该入口不依赖旧私有 Git 历史。

依赖和功能许可分别见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)、[外部资源清单](../EXTERNAL_DEPENDENCIES.json)和[独立 helper 源码](../../third_party/elevate/README.md)。程序包中的 `app/resources/veyra-notices/` 保留应用及第三方声明，`app/resources/third-party-sources/elevate/` 提供随包 helper 的完整对应源码。源码与包中构建提交保持一致，不将 Veyra 应用统一改标为 helper 的许可。
