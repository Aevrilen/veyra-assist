# 1.5.2-beta.3：自动定位、首页快捷开关和内置更新日志

这是 Windows x64 预发布，仍在开发中。相对上一公开 Mini 修复版，本版加入支持布局中的自动定位、首页快捷开关和离线更新日志；保留旧版本，不覆盖旧附件。

## 使用变化

- **自动定位**：进入支持的选人布局后，保持客户端前台及窗口稳定，由程序自动定位候选席和队友卡片。首次使用不再要求手动点击准备定位或经过首次定位页面；旧页面链接跳回首页。几何缓存仅保存布局数据，后续使用仍需验证窗口与双帧图像，不能将一次成功视为所有 DPI、布局或客户端通用。
- **首页快捷开关**：对局悬浮窗、自动接受、自动匹配与原设置页使用相同持久设置。对局悬浮窗保持原显示方式和快捷键，区别于已停用的 Mini。自动接受缺省开启、已有明确 false 保留；自动匹配缺省关闭。
- **内置更新日志**：主窗口右下角、功能搜索旁提供入口；内容随程序打包，可离线查看。未读版本显示“新”标记，打开后保存已读版本。此功能提供版本说明，不等于自动下载安装更新。
- **继续保留**：Mini 白框窗口及其入口停用，Mini 倒计时和临时操作按钮不恢复。选人辅助、海克斯识别、装备推荐与日志反馈沿用现有实现；本版没有新的局内 OCR 修复。

请下载 Release Assets 中带版本号的完整程序 ZIP 和说明，解压至独立、较短目录后运行“启动Veyra.cmd”，不要从压缩包内直接运行。先自行退出旧实例，不覆盖正在运行的文件。新包 user-data 为空；保留旧配置时先退出程序并备份，再按随包说明迁移。不要公开原始日志或整份 user-data，反馈应通过私密渠道提交脱敏资料。
