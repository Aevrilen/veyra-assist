# Mini 白框修正版 · 1.5.2-beta.2-mini-fix.20261015

本版针对原版 Mini 白框自动弹出、抢前台的问题，停用旧 Mini 窗口及其入口。它是独立 Windows x64 预发布，保留上一版；仍在开发中，尚未完成本版 GUI 或真实游戏验收。

## 变化与保留范围

- Mini 不再创建、自动显示或通过手动入口唤起；关闭相关托盘、标题栏、多窗口设置和搜索入口。旧设置继续保留，但不再启用 Mini。
- Mini 倒计时、状态显示和该窗口中的临时取消／拒绝按钮随窗口移除。不能将这些界面能力描述为仍然保留。
- 自动接受、自动匹配核心及主窗口持久设置保留。新配置／缺省键默认开启自动接受，已有明确 false 保留；自动匹配默认关闭。
- 选人辅助、海克斯识别、装备推荐、手动准备的两帧定位建议及反馈 ZIP 代码沿用上一版。本版未加入免点击自动定位、README 持久化或装备展开等后续改动。

使用时解压到新目录，运行包内“启动Veyra.cmd”。请先自行退出旧实例；不要覆盖正在运行的目录。新包 user-data 初始为空。需要保留旧设置时，先退出所有 Veyra 实例、备份后再按随包说明复制；不要公开或上传整份 user-data。

定位仍需在定位页手动准备，切回客户端并保持窗口稳定，等待两帧建议、核对后保存。反馈入口仍为“帮助修复 → 导出反馈 ZIP”，不会自动上传；反馈应走私密渠道，不公开原始日志或私人配置。
