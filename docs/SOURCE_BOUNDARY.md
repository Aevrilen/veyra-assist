## 使用模拟接口

使用 Node 24，无需安装依赖或运行游戏：

```sh
node public/demo.mjs
node --test public/recognition-provider.test.mjs
```

`getSnapshot()` 返回 `kind: "mock"`、`liveRecognition: false`、状态及三个展示槽。
槽位为 `null` 或 `{ id, title, score }`；示例名称和分数完全人工生成。
`showExample()` 供界面开发显示示例，`reset()` 清空结果。
消费者读取的是副本，不能修改提供方内部状态。

这是独立的展示层接口示例，未替换 Electron 应用原有内部模块。
完整的当前识别功能需要私有模块与对应运行依赖；运行模拟示例不证明真实识别可用。
本次没有改变公开 Release、安装包、附件或现有程序。

## 重复导出

在私有源目录稳定后，使用一个尚不存在的目标目录：

```sh
node scripts/export-public-source.mjs SOURCE EMPTY_DESTINATION
```

脚本只复制清单内且 SHA-256 匹配的已审查源码，源文件有变化就停止。
目标是局部源码增量，不是完整应用。合并到公开基线后，按项目规则格式化改动文件，
再运行相关测试与类型检查。新增文件或摘要必须重新审查，不按目录自动扩大发布范围。
